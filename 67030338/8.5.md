### 1. วิธีคำนวณหมายเลขเกจ์ประจำตัว (Student-ID Gauge Assignment) กำหนดให้ $N = 338$ 
* **เกจ์ซ้าย (Channel A - Left):** $$\text{Left} = (338 \bmod 4) + 1 = 2 + 1 = \mathbf{3} \quad (\text{Retro 7-Segment})$$ * **เกจ์ขวา (Channel B - Right):** $$\text{Right} = (\lfloor 338 / 4 \rfloor \bmod 4) + 1 = (84 \bmod 4) + 1 = 0 + 1 = \mathbf{1} \quad (\text{Analog Speedometer})$$ * **ตรวจสอบ Anti-Collision Rule:** เกจ์ซ้าย (3) และเกจ์ขวา (1) ไม่ซ้ำกัน สามารถใช้งานได้เลย

### 2. หลักการทำงานของ JavaScript และ SVG 
1. **Polling Mechanism:** ใช้ `setInterval(pollTelemetry, 150)` ดึงข้อมูล JSON จาก API Endpoint `/api/telemetry` แบบ Real-time 
2. **Left Gauge (7-Segment):** รับค่า `data.channelA.percentage` นำมาแยกเป็นหลักสิบและหลักหน่วย แมพเข้ากับ Segment Truth Table (`SEGMENT_MAP`) เพื่อควบคุมเปิด-ปิดหลอด LED 7-Segment ให้สว่างเรืองนีออน 3. **Right Gauge (Speedometer):** รับค่า `data.channelB.percentage` คำนวณเป็นมุมองศาระหว่าง $-90^\circ$ ถึง $+90^\circ$ สั่งหมุนเข็มไมล์ด้วยคุณสมบัติ CSS `transform: rotate(...)` ---
