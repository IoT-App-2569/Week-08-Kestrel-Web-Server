### 1. การคำนวณชนิดเกจ์เฉพาะบุคคลตามโจทย์
นำเลขรหัสนักศึกษา 3 ตัวท้าย ($N = 052$ หรือ $52$) มาคำนวณตามสูตร:

* **เกจ์ซ้าย (Channel A):**
  $$\text{Left} = (N \pmod 4) + 1 = (52 \pmod 4) + 1 = 0 + 1 = 1$$
  👉 **ได้เกจ์หมายเลข 1: Analog Speedometer (หน้าปัดเข็มความเร็ว กวาดมุม -90° ถึง +90°)**

* **เกจ์ขวา (Channel B):**
  $$\text{Right} = (\lfloor N / 4 \rfloor \pmod 4) + 1 = (\lfloor 52 / 4 \rfloor \pmod 4) + 1 = (13 \pmod 4) + 1 = 1 + 1 = 2$$
  👉 **ได้เกจ์หมายเลข 2: Audio VU Meter (แถบหลอดไฟ LED 10 ดวง เขียว/เหลือง/แดง)**

### 3. อธิบายหลักการทำงานของฟังก์ชัน JavaScript ในการเชื่อมต่อข้อมูล
1. **การดึงข้อมูลแบบ Real-time (`pollTelemetry`):**
   * ใช้คำสั่ง `fetch('/api/telemetry')` ส่งคำขอแบบ Asynchronous ไปยัง Kestrel Web Server ทุกๆ 60 มิลลิวินาที ผ่าน `setInterval`
   * ข้อมูลที่ได้รับกลับมาเป็น JSON สองช่องสัญญาณ (`channelA` และ `channelB`)

2. **การอัปเดตเกจ์ฝั่งซ้าย (`updateLeftWidget`):**
   * รับค่า `percentage` (0 - 100%) แล้วแปลงเป็นมุมองศาด้วยสูตร:
     $$\text{angle} = -90 + \left(\frac{\text{percentage}}{100} \times 180\right)$$
   * สั่งหมุนเข็ม SVG ด้วย CSS Transform `rotate(${angle}deg)` เพื่อกวาดเข็มจาก -90° ไปถึง +90°

3. **การอัปเดตเกจ์ฝั่งขวา (`updateRightWidget`):**
   * คำนวณจำนวนหลอดไฟ LED ที่ต้องติดจาก 10 หลอด ด้วยสูตร:
     $$\text{activeCount} = \text{round}\left(\frac{\text{percentage}}{100} \times 10\right)$$
   * วนลูปตรวจสอบ ID ของหลอดไฟ `led-0` ถึง `led-9` แล้วเพิ่มคลาส `.active` เพื่อเปิดไฟนีออนเรืองแสงตามระดับความสูงของสัญญาณ (เขียว 6 หลอดแรก, เหลือง 2 หลอดกลาง, แดง 2 หลอดบนสุด)
