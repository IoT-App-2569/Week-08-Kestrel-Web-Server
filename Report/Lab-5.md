## 1. การคำนวณหมายเลขเกจ์เฉพาะบุคคล
> **รหัสนักศึกษา 3 ตัวท้าย (N):** 323

### เกจ์ซ้าย (Left)

- **สูตร:** $(N \pmod 4) + 1$
- **วิธีทำ:** 323 mod 4
- **ผลลัพธ์:** **หมายเลข [ 4 ]** -> ชนิดเกจ์: Liquid Level Tank

### เกจ์ขวา (Right)

- **สูตร:** $(\lfloor N / 4 \rfloor \pmod 4) + 1$
- **วิธีทำ:** 323 / 4 = 80 \rightarrow 80 \pmod 4 = 0 \rightarrow 0 + 1$
- **ผลลัพธ์:** **หมายเลข [ 1 ]** -> ชนิดเกจ์: Analog Speedometer

> *หมายเหตุ: หากซ้ำให้บวกเกจ์ขวาเพิ่ม 1*

## 3. อธิบายหลักการทำงานของฟังก์ชัน JavaScript
> *อธิบายหลักการทำงานของฟังก์ชัน `pollTelemetry` และการนำข้อมูล JSON จาก `channelA` และ `channelB` ไปอัปเดตหน้าปัดแต่ละฝั่ง*

**คำตอบ:**

ฟังก์ชัน `pollTelemetry` ใช้ `fetch('/api/telemetry')` เพื่อร้องขอข้อมูล JSON จากเซิร์ฟเวอร์แบบเรียลไทม์ เมื่อได้รับข้อมูลแล้วจะแยกอ่านค่าจาก `channelA` และ `channelB`

ค่า `channelA.percentage` ถูกส่งให้ `updateLeftWidget()` เพื่อคำนวณความสูงของน้ำในถัง โดยปรับค่า `height` และ `y` ของ SVG ให้ระดับน้ำเปลี่ยนตามเปอร์เซ็นต์

ค่า `channelB.percentage` ถูกส่งให้ `updateRightWidget()` เพื่อคำนวณองศาการหมุนของเข็ม Speedometer ตั้งแต่ `-90` ถึง `90` องศา

ทั้งสองฟังก์ชันอัปเดตค่าตัวเลขเปอร์เซ็นต์บนหน้าจอด้วย

`setInterval(pollTelemetry, 150)` ทำให้ระบบดึงข้อมูลใหม่ทุก 150 มิลลิวินาที จึงทำให้เกจ์ทั้งสองตอบสนองต่อข้อมูลแบบต่อเนื่อง
