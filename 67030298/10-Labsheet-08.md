# สรุปผลการทดลอง ใบงานปฏิบัติการที่ 08-5 (Labsheet 8.5)
## ศูนย์ควบคุมเซนเซอร์คู่ IoT แบบเรียลไทม์ (Dual-Channel IoT Command Center)

### 1. วิธีคำนวณหาชนิดของเกจ์

**รหัสนักศึกษา** คือ 67030298 (3 ตัวท้ายคือ N = 298)

**การคำนวณ:**
- **เกจ์ซ้าย** = (298 mod 4) + 1 = 2 + 1 = 3 (Retro 7-Segment)
- **เกจ์ขวา** = (floor(298 / 4) mod 4) + 1 = 74 mod 4 + 1 = 2 + 1 = 3
- **เกิดการซ้ำกัน จึงบวกเกจ์ขวาเพิ่ม 1** คือ 3 + 1 = 4 (Liquid Level Tank)

**สรุปสิ่งที่ต้องสร้าง:**
- **เกจ์ซ้าย (CH-A)** Retro 7-Segment
- **เกจ์ขวา (CH-B)** Liquid Level Tank
