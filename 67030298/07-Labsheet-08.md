# สรุปผลการทดลอง ใบงานที่ 8.2 (Labsheet 8.2)
## การสตรีมสัญญาณแอนะล็อก ESP32 ออกพอร์ตสื่อสารอนุกรม (UART)

### Checkpoint 2.1 ทดสอบความเข้าใจ
**1. ใน ESP-IDF v6.x ฟังก์ชัน `adc_oneshot_read()` คืนค่าผลลัพธ์เป็นตัวเลขแบบใด และมีช่วงค่าต่ำสุด-สูงสุดเท่าใดเมื่อตั้งค่าเป็น `ADC_BITWIDTH_12`**
> ได้ค่าเป็นตัวเลขจำนวนเต็มตั้งแต่ 0 ถึง 4095

**2. ทำไมเราจึงต้องกดปุ่ม `Ctrl + ]` เพื่อปิด ESP-IDF Monitor ก่อนที่เราจะรันโปรแกรมฝั่ง C# Kestrel ในใบงานถัดไป**
> เพื่อคืนพอร์ต COM ให้ระบบ ถ้าไม่ปิด Kestrel จะเข้าไปอ่านข้อมูลไม่ได้เพราะพอร์ตโดนแย่งใช้อยู่

### ภารกิจท้าทาย (Micro-Challenge) สลับมาใช้ LDR เซนเซอร์แสง
**สรุปผลการสังเกตค่า ADC ที่หน้าจอ Terminal**
- **แสงไฟห้องปกติ:** ค่าจะวิ่งอยู่ประมาณ 1600 - 1700
- **เอามือปิดบังแสง (มืด):** ค่าจะลดลงมาเหลือประมาณ 900
- **เอาไฟฉายส่องจ่อ (สว่างจ้า):** ค่าพุ่งสูงขึ้นไปอยู่ในช่วง 2000 - 3700

**ตัวอย่าง Log บางส่วนจาก Terminal**
```text
[SYSTEM] ESP-IDF v6.x Potentiometer Stream Starting...
[SYSTEM] ADC Initialized. Streaming raw values @ 115200 bps...
1644  <-- (ไฟห้องปกติ)
1642
917   <-- (เอามือปิดบังแสง)
916
3747  <-- (ใช้ไฟฉายส่อง)
3754
```
