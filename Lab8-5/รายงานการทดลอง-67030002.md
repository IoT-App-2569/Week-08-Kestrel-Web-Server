### 2. การคำนวณเกจ์เฉพาะบุคคล

เลขรหัสนักศึกษา 3 ตัวท้ายคือ `N = 002` หรือ `N = 2`

**เกจ์ซ้าย**

`Left = (N mod 4) + 1 = (2 mod 4) + 1 = 2 + 1 = 3`

ดังนั้น เกจ์ซ้ายคือ **หมายเลข 3: Retro 7-Segment**

**เกจ์ขวา**

`Right = (floor(N / 4) mod 4) + 1`

`= (floor(2 / 4) mod 4) + 1 = (0 mod 4) + 1 = 1`

ดังนั้น เกจ์ขวาคือ **หมายเลข 1: Analog Speedometer** เกจ์ทั้งสองไม่ซ้ำกัน จึงไม่ต้องใช้กฎป้องกันเกจ์ซ้ำ

### 3. วัตถุประสงค์

1. สร้าง Kestrel Web Server สำหรับรับและให้บริการข้อมูลเซนเซอร์ 2 ช่องสัญญาณ
2. แสดงข้อมูล Channel A และ Channel B แบบเรียลไทม์ด้วย JavaScript Polling
3. แสดงค่า Channel A ด้วย Retro 7-Segment ตามเกจ์หมายเลข 3
4. แสดงค่า Channel B ด้วย Analog Speedometer ตามเกจ์หมายเลข 1
5. ออกแบบหน้าเว็บแบบ Responsive สำหรับเดสก์ท็อปและสมาร์ตโฟน

### 4. อุปกรณ์และซอฟต์แวร์

- บอร์ด ESP32 พร้อม Potentiometer สำหรับ Channel A
- สาย USB และ USB-to-UART Bridge
- .NET 8 และ ASP.NET Core Kestrel
- แพ็กเกจ `System.IO.Ports` เวอร์ชัน 8.0.0
- เว็บเบราว์เซอร์ Google Chrome หรือ Microsoft Edge
- โปรเจกต์ `Lab8-5/Kestrel_Dual_Dashboard`

### 5. วิธีดำเนินการทดลอง

1. สร้างโปรเจกต์ `Kestrel_Dual_Dashboard` และติดตั้งแพ็กเกจ `System.IO.Ports`
2. สร้าง `DualChannelStateStore` สำหรับเก็บค่าเซนเซอร์สองช่องแบบ Thread-Safe
3. สร้าง `DualSerialBridgeWorker` เพื่ออ่านข้อมูลจาก ESP32 และสร้าง Channel B จำลองเมื่อไม่มีข้อมูลช่องที่สอง
4. เปิดใช้งาน Static Files และสร้าง Endpoint `GET /api/telemetry`
5. คำนวณหมายเลขเกจ์จากรหัสนักศึกษา `67030002)
6. แสดง Retro 7-Segment ใน Channel A และ Analog Speedometer ใน Channel B
7. ให้ JavaScript เรียก API เป็นระยะเพื่ออัปเดตข้อมูลบนหน้าเว็บ
8. หมุน Potentiometer และสังเกตการเปลี่ยนแปลงของเกจ์

### 6. หลักการทำงาน

`DualSerialBridgeWorker` อ่านข้อมูลจาก Serial Port หากได้รับค่าตัวเลขหนึ่งค่า จะใช้เป็น Channel A และสร้าง Channel B ด้วยสัญญาณจำลอง หากได้รับข้อมูลรูปแบบ `valueA,valueB` จะใช้ค่าทั้งสองเป็นข้อมูลจากฮาร์ดแวร์

`DualChannelStateStore` จำกัดค่าดิบให้อยู่ในช่วง 0–4095 แล้วคำนวณแรงดันไฟฟ้าและเปอร์เซ็นต์ ก่อนส่งผ่าน Endpoint `/api/telemetry` ใน JSON ซึ่งประกอบด้วย `channelA`, `channelB`, `dataSource` และ `lastUpdated`

หน้าเว็บนำค่า `percentage` ไปอัปเดตวิดเจ็ตดังนี้:

- **Retro 7-Segment:** ปัดเปอร์เซ็นต์เป็นจำนวนเต็มแล้วแสดงตัวเลขบนจอ 7 ส่วน
- **Analog Speedometer:** แปลงเปอร์เซ็นต์เป็นมุมเข็มบนหน้าปัด ตั้งแต่ 0% ถึง 100%
- **Polling:** เรียก `/api/telemetry` ซ้ำเป็นระยะเพื่อแสดงข้อมูลล่าสุด

### 8. ปัญหาและการแก้ไข

หากไม่พบหรือเปิด Serial Port ไม่ได้ ระบบสามารถใช้ Simulation Mode เพื่อสร้างข้อมูลให้ทั้งสองช่องสัญญาณ หากได้รับข้อมูลจาก ESP32 เพียงช่องเดียว ระบบใช้ค่านั้นเป็น Channel A และสร้าง Channel B จำลอง

ผลคำนวณเฉพาะบุคคลของรหัส `67030002` กำหนดให้เกจ์ขวาเป็น **Analog Speedometer (หมายเลข 1)** แต่หน้า Dashboard ปัจจุบันยังแสดง **Liquid Level Tank (หมายเลข 4)** จึงควรเปลี่ยนวิดเจ็ตฝั่งขวาก่อนบันทึกผลว่าเกจ์ตรงตามโจทย์

### 9. สรุปผลการทดลอง

จากรหัสนักศึกษา `67030002` ได้เกจ์ซ้ายเป็น **Retro 7-Segment (หมายเลข 3)** และเกจ์ขวาเป็น **Analog Speedometer (หมายเลข 1)** ระบบ Kestrel จัดเก็บข้อมูลเซนเซอร์สองช่องและส่งข้อมูลผ่าน JSON API ได้ ส่วนการแสดงผลจะถือว่าตรงตามโจทย์เฉพาะบุคคลเมื่อหน้า Dashboard ใช้วิดเจ็ตทั้งสองชนิดตามที่คำนวณ และตรวจสอบการอัปเดตข้อมูลขณะรันระบบแล้ว
