## ⚠️ ข้อควรระวังเรื่องขนาดไฟล์ GIF

ไฟล์ GIF ทั้งสองรวมกันประมาณ **47 MB** ซึ่งใหญ่มากสำหรับ Git repository

| ประเด็น | รายละเอียด |
| :-- | :-- |
| **GitHub เตือนที่ 50 MB** | ไฟล์เดี่ยวเกิน 50 MB จะขึ้นคำเตือน และเกิน 100 MB จะ **push ไม่ได้เลย** |
| **ลบแล้วขนาดไม่หาย** | Git เก็บประวัติทุกเวอร์ชัน ถ้า commit ไปแล้วค่อยลบ ขนาด repo จะไม่ลดลง |
| **แต่ละครั้งที่แก้ไฟล์** | จะเพิ่มสำเนาใหม่เข้าไปอีกก้อน ไม่ได้เขียนทับของเดิม |

**ทางเลือกถ้าต้องการลดขนาด**

1. **ลดจำนวนเฟรมและความกว้าง** — คลิป 15–30 วินาทีที่ 10 fps กว้าง 800px มักเหลือ 3–5 MB
2. **แปลงเป็น MP4 แทน GIF** — ขนาดเล็กกว่า GIF ประมาณ 10 เท่าที่คุณภาพเท่ากัน
   แต่ Markdown แสดงผลอินไลน์ไม่ได้ ต้องใช้เป็นลิงก์ดาวน์โหลด
3. **อัปโหลดขึ้น GitHub Issue/Release แล้วลิงก์มา** — ไม่นับรวมในขนาด repo

> ถ้าอาจารย์รับไฟล์ผ่าน GitHub และขนาด repo ไม่ใช่ปัญหา ก็ปล่อยไว้แบบนี้ได้
