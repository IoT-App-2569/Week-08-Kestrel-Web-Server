## สนามทดลองสร้างสรรค์ (Creative Playground) — ต้องเลือกอย่างน้อย 1 อย่าง

| ตัวเลือก | วิดเจ็ต | เทคนิคหลักที่ได้ฝึก | ระดับความยาก |
| :--: | :-- | :-- | :--: |
| **A** | Audio VU Meter (LED 10 ดวง) | วนลูป toggle `class` ตามระดับสัญญาณ (เขียว 6 / เหลือง 2 / แดง 2) | ง่าย |
| **B** | Retro 7-Segment (2 หลัก) | Lookup table ของ segment `a`–`g` + แยกเลขหลักสิบ/หลักหน่วย | ปานกลาง |
| **C** | Liquid Level Tank | ปรับ `y` และ `height` ของ `<rect>` ตามระดับ (แกน Y ของ SVG ชี้ลง) | ปานกลาง |

**สิ่งที่เลือกทำ (รหัส 67030098): ตัวเลือก B — Retro 7-Segment ✅ ทำเสร็จแล้ว**

หน้าแดชบอร์ดจึงมี **2 หน้าปัด** วางเคียงกันแบบ Dual-Pane Grid:

| ตำแหน่ง | หน้าปัด | ที่มา |
| :-- | :-- | :-- |
| ซ้าย | **Analog Speedometer** | กิจกรรมที่ 2 (หน้าปัดหลักของใบงาน) |
| ขวา | **Retro 7-Segment 2 หลัก** | Creative Playground ตัวเลือก B |

เหตุผลที่เลือกตัวเลือก B: รหัส 67030098 ($N = 98$) เมื่อคำนวณตามกติกาของ**ใบงาน 8-5**
จะได้เกจ์ซ้าย = 3 (**7-Segment**) และเกจ์ขวา = 1 (**Speedometer**) — ตรงกับคู่นี้พอดี
ทำใน 8-4 ครั้งเดียวจึงนำไปต่อยอดใบงาน 8-5 ได้ทันทีโดยไม่ต้องเขียนวิดเจ็ตใหม่

> ⚠️ **กับดักสำคัญของใบงาน 8-4**
> โค้ดตัวอย่าง `pollTelemetry()` ในทั้ง 3 ตัวเลือก (A, B และ C) เขียนมาเป็น
> **ฟังก์ชันเต็มที่ใช้ทับของเดิม** และในนั้น**ไม่มีคำสั่งหมุนเข็มไมล์**
> (ไม่มีบรรทัด `document.getElementById('needle').style.transform = ...`)
>
> ถ้าคัดลอกมาวางทับตรงๆ ตามใบงาน **เข็ม Speedometer จะหยุดนิ่งทันที** เหลือหน้าปัดเดียวที่ขยับ
> ซึ่งจะเสียคะแนนหัวข้อ "ความสวยงามและความคิดสร้างสรรค์ของ SVG Dashboard" (25%)
>
> **วิธีแก้:** ต้อง**รวม**ทั้งสองหน้าปัดไว้ในลูปเดียว ไม่ใช่เขียนทับ

```javascript
async function pollTelemetry() {
    try {
        const res = await fetch('/api/telemetry');
        if (!res.ok) return;
        const data = await res.json();

        updateSpeedometer(data.percentage);   // หน้าปัดที่ 1 — ห้ามลืมบรรทัดนี้
        update7Segment(data.percentage);      // หน้าปัดที่ 2

        document.getElementById('disp-raw').textContent = data.rawValue;
        document.getElementById('disp-volt').textContent = data.voltage.toFixed(2) + ' V';
        updateAlert(data.alertLevel);
    } catch (err) {
        console.error('Polling error:', err);
    }
}
```

**ข้อจำกัดของ 7-Segment ที่ต้องรู้:** หน้าปัดมีแค่ 2 หลักตามสเปกใบงาน (00 – 99%)
โค้ดจึงใช้ `Math.min(99, ...)` ทำให้**ตอนหมุนสุดถึง 100% หน้าจอจะแสดง 99**
ไม่ใช่บั๊ก แต่เป็นข้อจำกัดของจำนวนหลัก — ถ้าต้องการให้ขึ้น 100 ต้องเพิ่ม `<g>` อีกหนึ่งหลักด้านซ้าย

## สูตรสำคัญที่ต้องเข้าใจ (Linear Mapping)

```javascript
// แปลงเปอร์เซ็นต์ (0-100) เป็นมุมของเข็ม (-90° ถึง +90°) รวมช่วงกวาด 180°
function percentToAngle(percent) {
    return (percent / 100) * 180 - 90;
}
```

| ค่า `percentage` | มุมที่ได้ | ทิศทางของเข็ม |
| :--: | :--: | :-- |
| 0 % | −90° | ชี้ซ้ายสุด |
| 50 % | 0° | ชี้ตรงขึ้นบน |
| 100 % | +90° | ชี้ขวาสุด |

**ความนุ่มนวลมาจาก CSS ไม่ใช่ JavaScript** — JS อัปเดตค่ามุมเป็นก้าวกระโดดทุก 150 ms
ส่วน `transition: transform 0.15s ease-out` บนตัวเข็มเป็นตัวเติมภาพระหว่างก้าวให้ลื่นไหล
ค่า transition ควร**ใกล้เคียงกับคาบ polling** — ถ้าตั้งนานเกินไปเข็มจะตามมือไม่ทัน (หน่วง)
ถ้าสั้นเกินไปจะเห็นการกระตุกเป็นขั้น
